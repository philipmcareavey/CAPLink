What we found: this website and the CAPLink platform do not currently set any cookies at all. Sign-in uses a bearer token held in memory by the app, not a cookie, and there is no analytics or advertising script anywhere on this site or in the platform. There is currently no cookie consent banner, because there is currently nothing non-essential to ask consent for.

What this page covers

We checked this by looking at what the site and the platform's frontend code actually does, not by assuming a standard set of categories applies. Specifically: authentication is implemented as a bearer token kept in the page's own memory (see our published source), not as a session cookie; no first- or third-party analytics library is loaded on any page; and no embedded third-party content (video players, social widgets, and so on) is used anywhere that would set its own cookies.

This site does load web fonts (Google Fonts) directly from Google's servers for typography. That's an external resource request, not a cookie, and — as far as we've checked — Google's current font-serving setup does not set cookies for this kind of request. It does mean your browser makes a request to a Google-operated server when you load this site. if this needs to be stated more formally (e.g. self-hosting the fonts instead), that's a real, small, reasonable change to make.

How to withdraw consent

Because nothing non-essential is currently set, there's nothing to withdraw consent for today. If that changes — for example, if analytics is added in future — we'll add a proper consent mechanism (a cookie banner offering a genuine accept/reject choice, not a single "accept" notice) before any non-essential cookie is set, and this page will be updated to reflect exactly what's added, when, and why.

Questions

If you have a question about this notice, contact us at contact.html#data-protection. See also our privacy policy for how we handle personal data more broadly.
